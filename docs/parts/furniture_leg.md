# Специфікація деталі: Меблева ніжка (C-профіль)

> Заповнено за шаблоном `docs/18_NEW_PART_SPEC.md` (yurii + архітектор, 2026-07-27).
> Джерело: параметричне креслення yurii (3 види) + відповіді 2026-07-27.
> ⚠️ Два припущення потребують підтвердження перед стартом — див. §9.

## 1. Ідентифікація

- **name_uk**: Меблева ніжка
- **name_en**: Furniture leg
- **slug**: `furniture_leg`
- **type**: **нова базова Деталь** + продуктовий пресет зверху (див. §7)

**Чому нова Деталь, а не пресет наявної.** Топологія — C/U-профіль (3 сегменти,
2 гиби в ОДИН бік), тобто родич `wall_shelf`. Але `wall_shelf` не підходить
числами й семантикою:

| Вимога                          | `wall_shelf` зараз                            |
| ------------------------------- | --------------------------------------------- |
| C (ширина) 30–120 мм            | `width_mm` min **100** ❌                     |
| B (лапка) 30–150 мм             | `front_lip_mm` max **100** ❌                 |
| отвори: відступ від краю + крок | auto-grid `rows×cols×margin` — інша модель ❌ |
| лейбли «ніжка/пластина/лапка»   | «полиця/задня стінка/фронт-губка» ❌          |

Перевикористовується **unfold-машинерія двох односпрямованих гибів**
(перевірена на `wall_shelf`); нова — лише схема, лейбли, діапазони, розкладка
отворів.

## 2. Геометрія

**Референс:** параметричне креслення (3 види: профіль, фронт, вид зверху).

**Сегменти** (обхід від вільного краю монтажної пластини):

- `A` — монтажна пластина (горизонтальна, кріпиться до дна меблів, з отворами)
- `H` — вертикальна стінка (висота ніжки)
- `B` — опорна лапка (горизонтальна, під підкладку)

**Гиби:** 2 × 90°, **обидва в один бік** (C-профіль: A і B відходять від
вертикалі в однаковому напрямку). `bends: [down, down]`.

**Радіус:** не задається користувачем — **авто-мінімум за товщиною** з
`bend-machine-esi.yaml`:

| t, мм       | 2.0 | 3.0 | 4.0 | 5.0 |
| ----------- | --- | --- | --- | --- |
| R_inner, мм | 1.0 | 2.5 | 2.5 | 4.0 |

**Самоклейна підкладка** — НЕ частина деталі (обирає клієнт окремо); усі
розміри стосуються металу.

## 4. Отвори — авто-розкладка

Отвори **лише на монтажній пластині `A`**, сітка `hole_rows × hole_cols`,
позиції обчислюються автоматично (користувач не вводить координати):

**Від вільного краю** відступ залежить від габариту тієї самої грані (рішення
yurii 2026-07-27): грань < 50 мм → 2·d; грань ≥ 50 мм → 4·d.

**Від вертикальної стінки** відступ **фіксований 20 мм** (рішення yurii
2026-07-28, ergonomics: простір для викрутки/шурупокрута). База відліку —
**край розміру A**, тобто зовнішня грань вертикалі; не залежить ні від `t`,
ні від `R`, тож розмір читається користувачем без пояснень.

Обидва відступи підпирає технологічний мінімум, який ніколи не порушується:

```
base(L)      = L < 50 ? 2·d : 4·d         # L — габарит грані, від якої міряємо
margin(L)    = max(base(L), d/2 + 2·t)    # від вільного краю до ЦЕНТРУ отвору
safe_from_A  = 3·t + 2·R + d/2            # мін. від краю A до ЦЕНТРУ (§5.2)
anchor_A     = A − max(20, safe_from_A)   # ряд, найближчий до вертикалі
pitch_min    = d + 2·t                    # центр-у-центр (перемичка ≥ 2·t)

зона по A : [margin(A) … anchor_A]        # ряд біля стінки прибитий до anchor_A
зона по C : [margin(C) … C − margin(C)]   # симетрично, як раніше
решта рядів розподіляється рівномірно (патерн corner_angle auto-grid);
при hole_rows = 1 єдиний ряд стає на anchor_A (сенс фіксованих 20 мм)
```

`safe_from_A` — розкладка §5.2 у координатах від краю A: тангенс гибу лежить
на `(R + t)` від краю, далі `2·t + R` до КРАЮ отвору і `d/2` до центру.

| t, мм             | 2.0 | 3.0 | 4.0 | 5.0       |
| ----------------- | --- | --- | --- | --------- |
| R (авто)          | 1.0 | 2.5 | 2.5 | 4.0       |
| `safe_from_A`, мм | 10  | 16  | 19  | **25**    |
| фактичний відступ | 20  | 20  | 20  | **25** ⚠️ |

> **Єдина комбінація, де 20 мм недосяжні — t = 5 мм** (потрібно 25). Там
> `anchor_A` автоматично відсувається до 25 мм; фіксовані 20 діють на
> t = 2/3/4. При t = 4 запас лише 1 мм — це нормально, але варто знати.

Контрольний приклад (A=70, C=45, t=2, R=1, d=4): margin(A) = max(16, 6) = **16**
(бо A ≥ 50), margin(C) = max(8, 6) = **8** (бо C < 50), anchor_A = 70 − 20 =
**50** → зона по A = [16 … 50], крок `y` = **34 мм**; зона по C = [8 … 37],
крок `x` = **29 мм**.

> Технологічний мінімум перекриває base при великих товщинах: для t = 5 мм
> `d/2 + 2·t` = 12 > 2·d = 8, тож на вузькій грані margin стане 12, не 8.

## 5. Обмеження (валідація; підтверджено yurii 2026-07-27)

1. **Від краю листа до КРАЮ отвору ≥ 2·t** → до центру: `margin ≥ d/2 + 2·t`.
2. **Від лінії гибу до КРАЮ отвору ≥ 2·t + R** (формула `a·t + R`, a = 2.0 для
   холоднокатаної — уже в `bend-machine-esi.yaml`) → до центру `+ d/2`.
   Інакше отвір деформується при гибці.
3. **Ряд біля вертикалі — 20 мм від краю A** (ергономіка, рішення yurii
   2026-07-28). Це НЕ мінімум, а цільове значення: якщо `safe_from_A` (п. 2)
   вимагає більше — виграє технологія (t = 5 мм → 25 мм).
4. **Крок між отворами ≥ `d + 2·t`** (перемичка між отворами ≥ 2·t — та сама
   логіка, що й для краю). Нове правило: фіксовані 20 мм звужують робочу
   зону, тож при малих A сітка перестає вміщатись раніше, ніж раніше.
5. **Мін. полиця після гиба ≥ 7.5 мм** (CLAUDE.md §7) — A і B задовольняють
   з великим запасом за своїми min.
6. **Сітка має вміститись:** якщо зона коротша за `(rows − 1) · pitch_min` —
   Zod-issue на `hole_rows`, експорт блокується. Найгірший кут діапазону:
   A = 50, t = 5 → зона [16 … 25] = 9 мм < `pitch_min` = 14 → **дозволено
   лише 1 ряд**. Це очікувана поведінка, не баг.
7. **Радіус ∈ allowed_inner_radius_mm[t]** — гарантовано авто-вибором мінімуму.

- Товщини 2.0 / 3.0 / 4.0 / 5.0 мм — усі присутні в матриці машини.
- Інші матеріали у v1 не пропонуються (рішення yurii).

## 7. Продуктовий шар

- **Назва в каталозі:** «Меблева ніжка»
- **Use cases:** ніжки для тумб і комодів; опори для лавок і журнальних
  столиків; підйом корпусних меблів під плінтус.
- **Fixed для пресету:** матеріал (холоднокатана), Ø отвору 4 мм, кут 90°.
- **Editable:** A, H, B, C, товщина, кількість отворів.
- **Прев'ю:** згенерувати PNG зі студії (як для інших шаблонів).
- **Розрахунок навантаження:** у v1 **НЕ включається** (рішення yurii
  2026-07-27; кандидат на майбутній issue).

## 8. Контрольний приклад (golden fixture)

**Вхід:** `cold_rolled_steel`, t = **2.0 мм**, R = **1.0 мм** (авто-мінімум),
A = **70**, H = **100**, B = **35**, C = **45**, отвори 2×2 Ø4.

**Розрахунок розгортки** (K = 0.40, гиб 90°):

```
BA      = (π/2)·(R + K·t) = 1.5707963·(1.0 + 0.8)   = 2.827433 мм  (кожен гиб)
пряма A = A − (R + t)     = 70 − 3                  = 67.000 мм
пряма H = H − 2·(R + t)   = 100 − 6                 = 94.000 мм
пряма B = B − (R + t)     = 35 − 3                  = 32.000 мм
──────────────────────────────────────────────────────────────────
L_flat  = 67 + 94 + 32 + 2·2.827433                 = 198.655 мм
```

**Очікувані значення для тесту (точність 0.1 мм):**

| Величина                                        | Значення                  |
| ----------------------------------------------- | ------------------------- |
| Довжина розгортки                               | **198.65 мм**             |
| Ширина заготовки                                | **45.00 мм**              |
| Лінія гибу 1 (від вільного краю A)              | 67.000 … 69.827 мм        |
| Лінія гибу 2                                    | 163.827 … 166.655 мм      |
| Центри отворів по довжині (від вільного краю A) | **16.0 і 50.0 мм**        |
| Те саме, від краю розміру A (вертикаль)         | 54.0 і **20.0 мм** (фікс) |
| Центри отворів по ширині (від краю C)           | **8.0 і 37.0 мм**         |
| Габарит готової деталі                          | 70 × 100 × 45 мм          |
| Маса (ρ = 7850 кг/м³)                           | ≈ 0.140 кг                |

**Конвенція розмірів (підтверджено yurii 2026-07-27): A / H / B — ЗОВНІШНІ
габарити.** A — від вільного краю пластини до зовнішньої грані вертикалі;
H — повна висота від верхньої до нижньої грані; B — від вільного краю лапки
до зовнішньої грані вертикалі.

> Розрахунок виконав архітектор за K-фактором з `bend-machine-esi.yaml`;
> **звірено yurii у SolidWorks 2022 (2026-07-28)** — усі значення в допуску.
> Позиції отворів оновлено після рішення про фіксовані 20 мм (§4).
