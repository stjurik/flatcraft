GUARD-ПРАВИЛА

- Verify-then-act: перед КОЖНИМ merge — `gh pr checks <N>`, дочекатись
  завершення. Червоний CI, конфлікт або `mergeStateStatus != CLEAN` → STOP з
  логом. «Дотискати» заборонено.
- Force-push заборонено (оновлення гілки — `git merge origin/main`, не rebase).
- Максимум ДВІ спроби тріажу за прогін (крок 3 + одна повторна після
  діагностики). Далі — STOP зі звітом, навіть якщо здається, що «ще одна
  гіпотеза точно спрацює».
- Після кожного виклику `agy` — `git status --short`; стороння зміна поза
  `docs/promts/inputs/*` → `git restore` + рядок в інцидент-звіт (не мовчки).
- Нічого не вигадуй: кожне твердження про стан CI/issue/коду — з команди, а не
  з пам'яті. Після кожного кроку — статус одним рядком.
- Робоче дерево yurii не чіпай: у гілці `feat/migrate-z-bracket` лежить
  незакомічена міграція z_bracket (Run 7). Docs-правки цього run'у — окремими
  гілками від свіжого `origin/main`.

    `origin/main`, PR, зелений CI, merge. Прогін НЕ вважається завершеним, поки
    цей PR не змержено.
