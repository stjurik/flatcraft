2. Додати ФІНАЛЬНИЙ крок-верифікатор термінального стану:

```yaml
- name: Verify issue reached a terminal state (ADR-035 §2)
  if: always()
  env:
    GH_TOKEN: ${{ github.token }}
  run: |
    labels=$(gh issue view ${{ github.event.issue.number }} \
      --repo "$GITHUB_REPOSITORY" --json labels --jq '[.labels[].name]|join(",")')
    echo "labels: $labels"
    n=0
    for l in ai-plan-ready ai-architectural ai-need-info; do
      case ",$labels," in *",$l,"*) n=$((n+1));; esac
    done
    if [ "$n" -ne 1 ]; then
      echo "::error::Тріаж завершився, але issue не має РІВНО одного" \
           "термінального лейбла (знайдено: $n). Стан: $labels"
      exit 1
    fi
```

на #84 локально, не вигадуй `--jq`-вираз). Крок ставиться ПІСЛЯ
