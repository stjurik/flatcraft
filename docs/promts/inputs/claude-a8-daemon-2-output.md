- Чи вимикає згенерований lefthook хук також при `LEFTHOOK=false`, а не лише при `=0`. У worktree немає `node_modules/lefthook*`, шаблон хука прочитати не було звідки.
- Шлях `last-results` в `a8-guard.sh.j2`, щоб довести, що `test.sh:178` не порожній: шаблон guard не читав.
- Чи трапляється в реальному лозі з `--output-format json` цитата сигнатури 401 у невдалому прогоні. Поведінку класифікатора на такому лозі показано, частоту — ні.
