# Вхід рев'ю №1 — дизайн демона черги A8

**Роль для тебе:** незалежний Рев'юер. **Обмеження:** не виконуй bash (він тут тихо відхиляється), читай лише `read_file`. Пиши **виключно** у `docs/promts/inputs/agy-a8-daemon-1-output.md`. Кожне фактичне твердження підкріплюй цитатою з файла і номером рядка. Якщо чогось не можеш перевірити читанням — так і пиши «не перевіряється читанням».

## Що прочитати

1. `infra/ansible/roles/a8/templates/a8-tick.sh.j2` — демон: один тік = щонайбільше одна задача, потім процес завершується. Стан задачі = тека, де лежить її файл (`queue/`, `running/`, `done/`, `failed/`, `rejected/`).
2. `tools/scripts/a8-tick-logic.sh` — чисті функції: валідація запису черги, коди запобіжника, класифікатор виходу, пауза.
3. `infra/ansible/roles/a8/templates/a8-guard.sh.j2` — запобіжник: `check` (коди 0/10/11/12), `count`, `record ok|failed`.
4. `infra/ansible/roles/a8/templates/a8-run-agent.sh.j2` — обгортка запуску контейнера; сама викликає `a8-guard check`.
5. `infra/ansible/roles/a8/templates/a8-journal.sh.j2` — журнал супервізора.
6. `docs/03_DECISIONS.md` — ADR-039: пункт 3 (стан у git і черзі), пункт 4 (класифікатор), пункт 7 «Запобіжники».

## Два питання

**1. Який стан губиться, якщо процес помре посеред тіку?** Пройди кроки демона по порядку (0 сирота, 1 запобіжник, 2 вибір задачі, перенесення в `running/`, 3 worktree, 4 перевірка хука, 5 запуск агента, `count`, 6 класифікація, 7 push). Для КОЖНОГО кроку: якщо процес убито саме тут (OOM, ребут, `kill -9`), що лишиться на диску, що побачить наступний тік і чи буде це правдою. Особливо: лічильник денного ліміту, `last-results`, kill switch, гілка `ai/<id>`, worktree, запущений контейнер.

**2. Де fail closed тече?** Знайди шлях, яким задача без валідного `source`/`origin`/`oracle`, або з `source: external`, все ж потрапить до агента; або невідоме падіння буде записане не як `failed`; або стан запобіжника буде проігноровано. Назви рядок.

## Формат відповіді

Два розділи за питаннями. У першому — таблиця «крок → що на диску після смерті → що зробить наступний тік → правда чи ні». У другому — список знахідок з рядками. У кінці — «Що я не зміг перевірити читанням».
